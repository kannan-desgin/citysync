# Project Header Dependencies

Headers included:
- `pcf8591_adc.h` — PCF8591 ADC function declarations and I2C address.
- `rpi_gpio_qnx.h` — Raspberry Pi GPIO, ultrasonic, and servo declarations.
- `citysync_types.h` — Shared message structures, subsystem identifiers, message types, freshness/status values, intervals, and thread priorities used by the acquisition and TwinSync programs.
